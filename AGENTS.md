# PGR4-Android

Этот репозиторий содержит Android-порт Project Gotham Racing 4 для ARM64. Цель на OnePlus Ace 5 — стабильные 30 FPS и выше в заезде при внутреннем разрешении не ниже 1280×720.

## Рабочая среда

- Работай в `D:\GameDev\Ports\PGR4-Android`. Базовый диск извлечён в соседнюю папку `PGR4-Files`. Текущая сборка рассчитана на Title ID `4D5307F9`, Media ID `5A381A4E`, версию `0.0.0.1`.
- Сборка и настройка SDK описаны в [android/README.md](android/README.md). Для замеров используй вариант `:app:assembleBenchmark` и закреплённую в README ревизию Android-совместимого ReXGlue SDK.
- В `D:\GameDev\Ports` инструменты распаковки и хостовый ReXGlue лежат в `tools`, справочный PGR4 Native — в `references`, исходные и промежуточные файлы распаковки — в `archive`. Для локальной сборки используй `fh2-reference\sdk`. `android-sdk` и `gradle-cache` содержат локальные компоненты и кэш сборки.
- Храни образ, игровые файлы, сгенерированный гостевой код, APK и логи замеров локально. Проверяй staged diff перед коммитом. Рабочая ветка — `android/bringup`, удалённый репозиторий — `origin` (`Meller2/pgr4-android` на GitHub). Проверенные изменения коммить и отправляй в эту ветку. Сохраняй чужие изменения в рабочем дереве.

## Проверка на Ace 5

- Владелец разрешил перезапускать PGR4 для тестов без отдельного подтверждения. При подключённом и разблокированном телефоне запускай `android\quick-race.cmd` из корня проекта. Скрипт проходит заставки и меню до уличного заезда на Дворцовой площади на Ford Sierra Cosworth RS500, сложность Silver.
- Начинай замер после появления гоночного HUD. Для сравнения держи одинаковыми трассу, участок, камеру, способ управления и разрешение. Записывай версию сборки, фактический Vulkan-драйвер, настройки рендера и температуру или статус термального ограничения, если доступны. Для проверки цели сравнивай время кадров и просадки на продолжительном заезде.
- Используй проверенную конфигурацию Turnip как исходную для сравнений. Перед замерами сверяй выбранный драйвер по логу приложения. Для каждого кандидата проверяй изображение на трассе и фиксируй настройки, влияющие на качество. После эксперимента, который ухудшил изображение или стабильность, возвращай проверенную сборку и настройки.
